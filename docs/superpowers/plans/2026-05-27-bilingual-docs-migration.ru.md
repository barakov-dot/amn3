# План миграции документации на два языка

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Цель:** создать русские и английские версии всей текущей документации, не ломая старые ссылки и рабочий процесс проекта.

**Архитектура:** legacy-файлы без языкового суффикса остаются на месте. Для каждого документа создаются отдельные версии `.ru.md` и `.en.md`; существующий язык копируется без смысловых изменений, второй язык создается как эквивалентный перевод или сжатая рабочая версия для больших внутренних планов.

**Технологии:** Markdown, Git, существующая политика документации, `rg`, `git diff --check`, pytest.

---

## Файлы

- Создать пары `.ru.md` и `.en.md` для legacy-файлов в `docs/`.
- Создать пары `.ru.md` и `.en.md` для legacy-файлов в `docs/superpowers/specs/`.
- Создать пары `.ru.md` и `.en.md` для legacy-файлов в `docs/superpowers/plans/`.
- Не удалять и не переименовывать старые `.md` файлы без суффикса.
