# Открытые вопросы

## VPS

1. ОС первого VPS: решено, Debian.
2. Размещение бота: решено, отдельно от VPN-сервера.
3. VPS/SSH: решено, VPS уже есть и SSH-доступ доступен.
4. Нужен ли IPv6 или только IPv4?

## Сеть

1. UDP-порт: решено, генерировать любой порт больше `30000` и открывать его в `ufw`.
2. DNS для клиентов: решено, `1.1.1.1`.
3. Маршрутизация: решено, full tunnel `0.0.0.0/0`.
4. Пул VPN IP: базово `10.8.0.0/24`, но нужно поддержать расширение пула при росте больше 255 устройств.

## Доступы

1. Модель устройств: решено, один Telegram-пользователь может иметь несколько устройств, каждое устройство получает отдельный конфиг.
2. Лимит устройств: решено, максимум 5 устройств на пользователя.
3. Нужно ли ограничение трафика?
4. Нужно ли ограничение скорости?
5. Предупреждения: решено, за 7, 5, 3 и 1 день.

## Оплата

1. MVP: решено, тестовый режим бесплатный, с переключателем на ручную проверку/оплату.
2. Какой платежный провайдер выбрать первым позже?
3. Нужны ли промокоды?
4. Нужна ли автопродление подписки?

## Администрирование

1. Список Telegram ID администраторов известен?
2. Нужны ли роли: owner, admin, support?
3. Нужно ли логировать все действия админов в отдельный канал Telegram?

## Клиентские форматы

1. Основной клиент: AmneziaVPN, AmneziaWG native или оба?
2. Нужно ли выдавать отдельные инструкции для Windows, Android, iOS, macOS?
3. Нужно ли подтверждать формат импортируемой ссылки экспериментально на клиенте AmneziaVPN?

## Политика хранения

1. Хранить ли private key пользователя в базе для повторной выдачи конфига?
2. Или хранить только зашифрованный `.conf`/секреты?
3. Какой срок хранения логов и заявок?
