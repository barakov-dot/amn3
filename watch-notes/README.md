# Watch Notes

Здесь ведутся периодические наблюдения за внешними проектами:

- новые релизы;
- изменения лицензии;
- security-relevant изменения;
- новые функции;
- breaking changes;
- изменения installation или deployment model;
- изменения UX, API и документации.

```md
- Источник:
```
