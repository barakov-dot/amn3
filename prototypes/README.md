# Prototypes

Здесь могут появляться собственные прототипы и проверки гипотез.

## Правила

- Не копировать код из внешних проектов без отдельной проверки лицензии.
- Не переносить прототип в `amn2` без тестового плана.
- Отделять proof-of-concept от production-дизайна.
- Для операций с VPN-серверами предусматривать dry-run, audit log и rollback-подход.
- Для работы с секретами заранее описывать storage, rotation и revoke.

## Перед стартом прототипа

Нужно указать:

- какую идею проверяем;
- из какого upstream-анализа она пришла;
- почему нельзя проверить ее только документационно;
- какие риски есть;
- какие тесты подтвердят, что гипотеза полезна;
- почему прототип не нарушает лицензионные ограничения.
