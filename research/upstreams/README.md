# Upstream-анализ

В этой папке хранятся карточки внешних VPN-связанных проектов. Допускаются и не-VPN UX/design references, если они нужны для будущего operator UI и явно помечены как reference-only.

Каждая карточка должна отвечать на вопросы:

- что это за проект и какую задачу он решает;
- какая лицензия указана в репозитории;
- можно ли переносить код, идеи или только общие подходы;
- какие архитектурные решения полезны для `amn2`;
- какие решения полезны для будущего гибридного проекта;
- какие UX- и production-подходы стоит изучить;
- какие риски мешают переносу;
- какой следующий шаг по исследованию.

## Reference-only карточки

- [VoltAgent/awesome-design-md](awesome-design-md.md) - коллекция DESIGN.md по известным сайтам; используем как источник паттернов для собственного `VPS-OPS-LAB DESIGN.md`, без копирования брендовой визуальной идентичности.
