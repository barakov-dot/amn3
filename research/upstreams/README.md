# Upstream-анализ

В этой папке хранятся карточки внешних VPN-связанных проектов.

Каждая карточка должна отвечать на вопросы:

- что это за проект и какую задачу он решает;
- какая лицензия указана в репозитории;
- можно ли переносить код, идеи или только общие подходы;
- какие архитектурные решения полезны для `amn2`;
- какие решения полезны для будущего гибридного проекта;
- какие UX- и production-подходы стоит изучить;
- какие риски мешают переносу;
- какой следующий шаг по исследованию.
